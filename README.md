# Fieldnote

Preview site for Fieldnote, a cologne brand that mixes every bottle after you order and labels it with your name, city and date.

Static HTML/CSS/JS, no build step. Hosted on GitHub Pages.

- `index.html` home
- `scents.html` house scents catalog
- `scent.html?s=<slug>` product page with live label preview
- `discovery.html` Discovery Set
- `how-its-made.html` fresh-fill process, ingredients, FAQ
- `assets/app.js` scent data, bottle/label SVG, fill dates, demo bag
- `assets/style.css` design system

Edit scents in the `SCENTS` array at the top of `assets/app.js`.
